Before you start:

- Verify the build by content, not the version string: 2026-10-21 run = `build/Zotero-OpenReader.xpi` 1.16.13-beta2 @ 8bf3240, installed bundle `content/zotero-tts.js` SHA-256 `5119a6b67329e1b790de7841ea97b35fcb48ad06a53d9746120efc47f722e498` (contains `arrowKeyBelongsToWidget`, `findPersistedSpeed`), `content/player-controls.js` SHA-256 `2abb1c65dad6fb8113520a58cdfcbd7bba8566f91bc0dc614ec638e72017674b` (earlier builds had different hashes; the beta10 line in the git history is superseded).
- Run `zotero_ping`, list plugins, baseline before installing, then install this exact XPI and run startup before opening fixtures. Use `fixture-a.pdf` and `return-key/return-key.epub` from `params.fixturesDir`.
- Run the group with `stopOnError: true`; collect full results from `.tmp/zotero-dev/<runId>/results/`. If a focused row stops the group, run `90-cleanup.js` separately.
- The owner reader is never selected for a command, pressed, repositioned or reopened. Output is muted; named prefs and user flags are restored after fixture players close, with memory written last.
- `00-baseline.js` stores the original values before applying its temporary mute; cleanup must treat `state.baseline.prefs` as authoritative for overlapping preferences.

Limits:

- 2026-10-21: Firefox 153 removed `nsIDOMWindowUtils.sendMouseEvent`; trusted clicks use `sendNativeMouseEvent` (screen CSS px × devicePixelRatio) and REQUIRE the Zotero window OS-active (`Services.focus.activeWindow` check in every script; `w.focus()` at script start; the harness app steals focus between bridge calls).
- 2026-10-21: the Appearance popup of this Zotero 11 build has no `input[type=range]` at all (only Reading Mode/Scrolling/Spreads/Split View/Themes rows) — the #212 slider sub-check is NOT TESTABLE; the popup-inside close is exercised with the player menu opened synthetically (`anchor.click()`) because opening the popup closes the menu (mutual light-dismiss).
- 2026-10-21: the outline expands/collapses with the `.expanded` class + child `li` count (no aria-expanded); arrows only act when the item is `.active` (click its `.title` first).
- 2026-10-21: `diagnostics.engine()` is keyed by `readers[].itemID` (not positional); `diagnostics.pluginPlayer()` is async and cannot be parsed under eval — inset evidence uses `frame.style.top` restore instead.
- The installed profile used for the 2026-09-17 pre-install probe was Zotero-TTS 1.12.11; HEAD 565d720 (`1.12.12-beta4`) was not installed. Its native player and Settings sliders reported 0.1 steps and Shift+C/X moved by 0.1. The focused `05-speed.js` run below supersedes the broad navigation and historical Settings rows for this speed verification; those rows were not run in this focused pass.
- The first candidate `05-speed.js` attempt stopped while `navigateToPane` raced Settings initialization; the script now waits for `Zotero_Preferences.navigation`, and the successful rerun is the one recorded below.
- Natural audio progression and perceived listening quality are reported from the fixture AudioContext separately; a suspended clock at `0` is NOT TESTABLE for natural listening.
- The first-frame traces are rectangle evidence sampled immediately and across resize settling; smooth motion itself is not claimed. A host resize ignored by Zotero is recorded as NOT TESTABLE.
- Fixture setup uses a direct segment seed only to choose a middle starting point; every navigation assertion clicks the real floating button and records the resulting source position.
- The bridge could not move the grip with synthesized pointer events, so edge movement uses the production exported drag adapter; actual menu rectangles remain measured. The real reader viewport reached `511px`; the long locale request was `290px`, both sides were `224.5px`, and the visible menu was constrained to `224.5px` on the roomier side.
- The available real provider pools did not expose more than 30 voices, so `07-voice-scroll.js` uses a disposable child UI snapshot with 60 synthetic options for this rendering-only check. It does not issue provider or voice selection commands on those entries; each layout reached a positive scroll range and passed the fixed-header/list-refresh assertions.
- `08-am-center-and-reload.js` uses an isolated installed child for numeric/error combinations and command dispatch, so it does not issue real speed/volume/mode changes or audio requests. It measured 36 floating cases: mode center diff 0px, frame/content 202 or 108, status hidden/visible 18/18, no overlaps, and all controls fit.
- The real EPUB cycle kept one child document with zero load events. After a 400ms setup settle, Top→A had no new `mask-resizing`; A→B and B→top sampled `mask-resizing` with `blur(10px)` at 100ms and cleared the class by 300ms. These are computed-style checks; subjective blur and perceived motion remain human observations.
- The first beta10 attempts corrected an isolated-frame measurement assumption (`window.frameElement` was null) and preset labels (speed `1.50×`, volume `50%`); the final named rerun passed.
- The final run recorded Zotero `AutoCompleteChild` `InvalidStateError` close-popup noise, two manifest-version warnings, and bounded machine audio-output-blocked messages; no dead-object error was observed.
- Fixture opening normalized the host from the baseline maximized state (`windowState:1`) to normal (`3`); `91-restore-host-window.js` restores the baseline host snapshot after cleanup. Settings was closed at baseline and remained intentionally closed.
