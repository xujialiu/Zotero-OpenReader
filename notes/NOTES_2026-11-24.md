## Windows Zotero can outlive its launcher (2026-11-24 11:04, issue #264)

On Windows with Zotero 10.0.8, the spawned parent exited while another
`zotero.exe` still held the disposable profile and data arguments. The
helper removed the data directory, then hit a locked `cert9.db`. Zotero's
database error named the disposable data path.

The private bridge reports the runtime PID. When it differs from the PID
returned by spawn, match it to the executable and both directory arguments
before recording it. Older session records can contain the exited
launcher's PID, so cleanup also checks for processes using the session.

With the same Zotero 10.0.8 installation and OpenReader 1.16.9 XPI, the
corrected helper reached READY with 27 completed startup steps. The PID
in the session record matched the Windows process with both directory
arguments. A session-bound ping succeeded. After close, the directory
and all disposable processes were gone and the three original personal
Zotero processes were still running.
